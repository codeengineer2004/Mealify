# Mealify 🍳

Mealify is a modern, interactive recipe discovery application built with React Native and Expo. It features a sleek grid layout, smooth animations, and a seamless user experience for browsing and saving your favorite recipes.

## ✨ Features

- **Dynamic Recipe Grid**: YouTube-style 4-column layout for easy browsing.
- **Interactive UI**: Fluid entrance animations and touch feedback using `react-native-reanimated`.
- **Favorites System**: Save and manage your preferred recipes.
- **Cross-Platform**: Designed for iOS, Android, and Web.

## 🛠️ Tech Stack

- **Framework**: [Expo](https://expo.dev/) (React Native)
- **State Management**: Redux Toolkit
- **Animations**: React Native Reanimated
- **Navigation**: React Navigation
- **Web Support**: React Native Web

## 🚀 Getting Started

### Prerequisites
- Node.js (LTS)
- npm or yarn

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the development server for web:
```bash
npm run web
```
The app will be available at `http://localhost:8081`.

## 🌐 Hosting

This project is configured for one-click deployment to **GitHub Pages**.

1. Update the `homepage` URL in `package.json`.
2. Run the deployment command:
   ```bash
   npm run deploy
   ```
